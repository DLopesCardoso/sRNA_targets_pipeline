# sRNA_targets_pipeline

Reproducible R workflow for bacterial small RNA target prediction, transcript context integration, motif analysis, functional enrichment and candidate prioritisation.

This repository contains the computational pipeline used to analyse candidate mRNA targets of the GcvB small RNA in *Actinobacillus pleuropneumoniae* serovar 8 strain MIDG2331.

## Workflow

The analysis is organised as sequential R scripts:

1. `00_extract_gbk_annotation.R`  
   Extracts reference annotation information from the MIDG2331 GenBank file.

2. `01_harmonise_target_predictions.R`  
   Harmonises TargetRNA2, IntaRNA and CopraRNA predictions to MIDG2331 locus tags and generates the curated candidate set.

3. `02_plot_prediction_overlap_upset.R`  
   Summarises overlap between prediction methods and generates the UpSet plot.

4. `03_plot_gcvb_interaction_regions.R`  
   Maps predicted mRNA interaction regions onto the GcvB sequence and conserved interaction regions.

5. `04_tss_consensus.R`  
   Integrates transcription start site calls from WT plate and broth TSS-enriched RNA-seq datasets.

6. `05_operon_context.R`  
   Integrates Operon-mapper predictions and assigns candidate genes to operon positions.

7. `06_integrate_transcript_context.R`  
   Combines target predictions, TSS information and operon context.

8. `07_plot_transcript_relative_interactions.R`  
   Maps predicted interactions relative to annotated CDS starts and transcript context.

9. `08_prepare_motif_windows.R`  
   Extracts transcript-oriented sequence windows for candidate and background genes.

10. `09_targeted_motif_enrichment.R`  
    Tests enrichment of the A/C-rich GcvB-associated motif and one-mismatch variants.

11. `10_plot_functional_enrichment.R`  
    Processes ShinyGO output and generates the functional enrichment figure.

12. `11_plot_string_network.R`  
    Retrieves and visualises STRING functional associations among candidate targets.

13. `12_export_appendix_table_A7.R`  
    Generates the compact appendix candidate table and a detailed candidate prioritisation table.

## Repository structure

```text
sRNA_targets_pipeline/
├── scripts/
├── data/
│   ├── raw/
│   └── reference/
└── results/
    ├── figures/
    ├── motif/
    └── tables/
```

`data/raw/` contains the input files required by the computational workflow, including target prediction outputs, TSS calls, Operon-mapper output and functional enrichment results.

`data/reference/` contains the MIDG2331 reference genome and annotation files used by the pipeline.

`results/` contains figures, processed tables, intermediate outputs and quality control files generated by the scripts.

## Reproducibility

Scripts are intended to be run sequentially from `00` to `12` from the repository root.

The workflow uses relative file paths. Set the working directory to the repository root before running the scripts.

Required R packages are loaded or installed within individual scripts where applicable.

## AI-assisted code development

Portions of the R code in this repository were developed and debugged with assistance from OpenAI ChatGPT. All scripts were subsequently reviewed, tested and validated by the authors. The authors are responsible for the analyses, outputs and interpretation of the results.

## RNA-seq data

Raw RNA-seq sequencing data are deposited separately in a public sequence repository. Processed transcript context information required for this workflow is included here.

The sequence data accession will be added to the associated manuscript and repository when available.

## Outputs

Key outputs include:

- curated GcvB candidate target set
- prediction method overlap summary
- GcvB interaction region mapping
- transcript and operon context tables
- motif enrichment analysis
- functional enrichment summary
- STRING functional association network
- appendix candidate table
- detailed candidate prioritisation table
